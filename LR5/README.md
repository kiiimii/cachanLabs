# Лабораторная работа №5 — анализ качества структуры

Программа принимает ориентированный граф в виде множества левых инциденций
`G⁻`, преобразует его в простой неориентированный граф и рассчитывает:

- структурную избыточность `K`;
- неравномерность распределения связей `ε²`.

## Запуск

```bash
cd LR5
python3 app.py
```

Для интерфейса используется стандартная библиотека Tkinter. Дополнительные
пакеты устанавливать не нужно.

## Формат ввода

Каждая строка содержит номер вершины и множество вершин, из которых в неё
входят дуги:

```text
G-(1) = {}
G-(2) = {1}
G-(3) = {1, 2}
```

Также разрешён сокращённый формат `3: 1 2`. Пустое множество можно записать
как `{}`, `∅`, `Ø`, `-` или `0`.

При преобразовании ориентированного графа направление дуг отбрасывается.
Если между двумя вершинами есть встречные дуги, они считаются одним ребром.
Петли не допускаются.

## Формулы

Пусть `n` — число вершин, `m` — число рёбер неориентированного графа, а
`ρᵢ` — степень вершины `i`.

```text
K = m / (n - 1) - 1

ρ̄ = 2m / n
ε² = Σ(ρᵢ - ρ̄)²
```

Чем больше `K`, тем больше в структуре избыточных связей. Значение `ε² = 0`
означает равномерное распределение связей по вершинам.
