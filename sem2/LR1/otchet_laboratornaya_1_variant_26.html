2. Постановка задачи

Предприятие планирует выпуск n видов продукции. Для изготовления продукции используются m видов ограниченных ресурсов: фонд времени оборудования, сырьё, трудовые ресурсы и другие производственные факторы. Известны нормы расхода каждого ресурса на единицу продукции, доступный запас каждого ресурса и прибыль от выпуска единицы каждого изделия.

До проведения послеоптимизационного анализа необходимо определить оптимальный объёмный план, обеспечивающий максимальную суммарную прибыль предприятия. После нахождения оптимума требуется оценить устойчивость плана к изменению исходных параметров.

Необходимо определить:

  1. оптимальные объёмы выпуска каждого вида продукции;
  2. максимальное значение целевой функции;
  3. остатки ресурсов и перечень дефицитных ресурсов;
  4. теневые цены ресурсов;
  5. интервалы изменения запасов ресурсов, сохраняющие текущий оптимальный базис;
  6. приведённые оценки продукции и допустимые интервалы изменения удельной прибыли;
  7. наличие альтернативного оптимального плана.

Послеоптимизационный анализ позволяет получить управленческую информацию без многократного повторного решения задачи. Он показывает, какие ресурсы ограничивают производство, насколько выгодно наращивать их запас и при каких изменениях экономических показателей действующий план сохранит оптимальность.

3. Построение математической модели

3.1. Переменные решения

Введём переменные:

xj ≥ 0 — объём выпуска продукции j-го вида,   j = 1, …, n.

Все переменные являются непрерывными и неотрицательными. В стандартной постановке предполагается, что продукцию можно выпускать в дробных объёмах либо выбранная единица планирования достаточно крупна.

3.2. Целевая функция

Пусть cj — прибыль от выпуска единицы продукции j. Тогда суммарная прибыль предприятия определяется выражением:

F(x) = c1x1 + c2x2 + … + cnxn → max.

В векторной форме целевая функция записывается как:

F(x) = cTx → max.

3.3. Ограничения по ресурсам

Обозначим через aij расход ресурса i на производство единицы продукции j, а через bi — доступный запас ресурса i. Для каждого ресурса выполняется ограничение:

ai1x1 + ai2x2 + … + ainxn ≤ bi,   i = 1, …, m.

Матричная запись модели имеет вид:

F = cTx → max;

Ax ≤ b;

x ≥ 0.

3.4. Переход к системе равенств

Для построения начального допустимого базиса в каждое ограничение вводится добавочная переменная si ≥ 0, характеризующая неиспользованный остаток соответствующего ресурса:

Ax + s = b.

Начальный базис составляют добавочные переменные. При неотрицательных запасах bi такое решение допустимо: объёмы выпуска равны нулю, а остатки ресурсов совпадают с их исходными запасами.

3.5. Показатели послеоптимизационного анализа

Пусть B — матрица столбцов ограничений, соответствующих переменным оптимального базиса, а cB — вектор их коэффициентов в целевой функции. Вектор теневых цен определяется как:

yT = cBTB−1.

Компонента yi показывает предельное изменение максимальной прибыли при увеличении запаса ресурса i на одну единицу, если найденный базис остаётся допустимым и оптимальным.

Для каждой переменной вычисляется приведённая оценка:

Δj = cj − yTAj.

В задаче максимизации текущий базис оптимален, если для всех небазисных переменных выполняется Δj ≤ 0. Для продукции, не вошедшей в план, отрицательная оценка показывает, насколько должна увеличиться её удельная прибыль, чтобы выпуск мог стать экономически выгодным.

Интервалы устойчивости запасов ресурсов

При изменении только запаса ресурса i на величину δ базисное решение изменяется по формуле:

xB(δ) = xB + δB−1ei.

Границы δ определяются из условий неотрицательности всех базисных переменных. Если d = B−1ei, то:

δmin = max(−xBk/dk) для dk > 0;

δmax = min(−xBk/dk) для dk < 0.

Следовательно, запас может изменяться в интервале [bi + δmin; bi + δmax] без изменения состава оптимального базиса.

Интервалы устойчивости коэффициентов прибыли

Для небазисного продукта допустимое увеличение прибыли ограничивается условием Δj ≤ 0. Для базисного продукта изменение коэффициента влияет на все оценки небазисных переменных, поэтому границы находятся из системы условий:

Δ′j = Δj − δ(B−1Aj)p ≤ 0.

Полученные интервалы действительны при изменении только одного параметра. Одновременное изменение нескольких параметров требует повторного решения задачи либо применения специальных правил совместной устойчивости.

4. Выбор и описание численного метода

Для решения задачи выбран прямой симплекс-метод. В отличие от исходного образца отчёта, программа не использует внешние оптимизационные библиотеки: все операции над симплекс-таблицей, выбор разрешающих элементов и расчёт характеристик устойчивости реализованы непосредственно на языке Python.

4.1. Последовательность симплекс-метода

  1. К матрице норм расхода добавляется единичная матрица добавочных переменных.
  2. Формируется начальный базис из остатков ресурсов.
  3. Для каждого столбца вычисляется приведённая оценка Δj.
  4. Если все оценки небазисных переменных неположительны, план оптимален.
  5. В противном случае выбирается переменная с положительной оценкой, вводимая в базис.
  6. По правилу минимального отношения определяется переменная, покидающая базис.
  7. Выполняется преобразование Жордана — Гаусса и пересчёт симплекс-таблицы.
  8. Действия повторяются до выполнения критерия оптимальности.

4.2. Обработка особых ситуаций

  • Если в разрешающем столбце отсутствуют положительные элементы, целевая функция не ограничена сверху.
  • Для предотвращения зацикливания при вырождении используется правило Бланда: из допустимых кандидатов выбирается переменная с наименьшим индексом.
  • Нулевые значения с погрешностью менее 10−8 очищаются от вычислительного шума.
  • Количество итераций ограничено значением 10 000.
  • Альтернативный оптимум определяется по нулевой приведённой оценке небазисного продукта.

4.3. Расчёт двойственных оценок

После получения оптимального базиса система BTy = cB решается методом Гаусса с частичным выбором главного элемента. Такой подход позволяет вычислить теневые цены без сторонних пакетов и обеспечивает устойчивость для рассматриваемого масштаба учебных задач.

6. Документ «Руководство оператора» по ГОСТ 19.505-79

6.1. Назначение программы

Программа предназначена для формирования оптимального объёмного плана производства и проведения послеоптимизационного анализа задачи линейного программирования стандартного вида. Приложение поддерживает произвольное число продуктов и ресурсов в пределах, удобных для табличного ввода.

6.2. Условия выполнения программы

Минимальные требования:

  • операционная система Windows 10/11 или современный дистрибутив Linux;
  • интерпретатор Python версии 3.10 или выше;
  • стандартный модуль tkinter для графического интерфейса;
  • не менее 100 МБ свободного дискового пространства.

Внешние библиотеки numpy, scipy и другие оптимизационные пакеты не требуются. В Linux при отсутствии Tk может потребоваться установка системного пакета python3-tk.

6.3. Запуск программы

Основной запуск графического интерфейса выполняется из каталога программы командой:

python3 script.py

Для Windows в зависимости от настройки интерпретатора может применяться команда:

6.5. Сообщения оператору

  • «Поле должно содержать число» — обнаружен некорректный формат ввода.
  • «Нормы расхода неотрицательны» — введено отрицательное значение расхода или запаса.
  • «Целевая функция не ограничена сверху» — модель допускает бесконечное увеличение прибыли.
  • «Вырожденный базис» — невозможно надёжно выполнить анализ устойчивости выбранного базиса.

7.5. Проверка прогноза по теневой цене

Пусть запас оборудования увеличен со 100 до 110 часов. Значение 110 находится внутри интервала [40; 160], поэтому состав базиса не изменится. Прогнозируемая максимальная прибыль:

F′ = 2300 + 15 · (110 − 100) = 2450.

Новый базисный план равен x1 = 46,67 и x2 = 16,67. Проверка целевой функции:

40 · 46,67 + 35 · 16,67 ≈ 2450.

Таким образом, теневая цена корректно прогнозирует изменение результата в пределах рассчитанного интервала устойчивости.

8. Верификация программной реализации

В программу включён режим автоматической самопроверки. Он запускается командой python3 script.py --self-test и содержит два контрольных случая.

  1. Основной тест: встроенный пример из трёх продуктов. Проверяются значение прибыли 2300, план [40; 20; 0] и теневая цена [15; 10; 0].
  2. Одномерный тест: max 3x при условии 2x ≤ 8. Эталонный результат: x = 4, F = 12, теневая цена 1,5.

Дополнительно проверена ситуация неограниченности: если прибыль продукта положительна, а его выпуск не расходует ни один ресурс, программа формирует сообщение «Целевая функция не ограничена сверху».

Файл успешно проходит синтаксическую проверку стандартным модулем py_compile. Консольный и графический режимы используют единое вычислительное ядро, поэтому изменение интерфейса не влияет на математические результаты.

9. Интерпретация результатов и выводы по работе

  1. Оптимальный план предусматривает выпуск 40 единиц изделия A и 20 единиц изделия B. Выпуск изделия C при текущей прибыли экономически нецелесообразен.
  2. Максимальная прибыль составляет 2300 условных денежных единиц.
  3. Узкими местами производственной системы являются оборудование и сырьё. Их запасы используются полностью, а теневые цены положительны.
  4. Увеличение запаса оборудования имеет больший предельный эффект, чем увеличение запаса сырья: 15 против 10 единиц прибыли на единицу ресурса.
  5. Трудовой ресурс имеет резерв 30 чел.-ч. Дополнительное увеличение его фонда без изменения других ресурсов неэффективно.
  6. Для включения изделия C в производственный план его прибыль должна увеличиться не менее чем до 25 единиц.
  7. Рассчитанные интервалы устойчивости позволяют оценивать небольшие изменения параметров без повторного запуска оптимизации.
  8. Разработанное приложение реализует симплекс-метод и послеоптимизационный анализ без сторонних вычислительных библиотек, поддерживает графический и консольный интерфейсы, а также сохранение моделей в JSON.

Таким образом, цель лабораторной работы достигнута: изучен и программно реализован алгоритм решения стандартной задачи объёмного планирования, выполнен послеоптимизационный анализ и дана экономическая интерпретация результатов.
