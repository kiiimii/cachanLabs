# Лабораторная работа №4 — алгоритм Левита

Программа получает матрицу расстояний между смежными вершинами `D` и с
помощью алгоритма Левита строит матрицу кратчайших путей `U` размером `n × n`.
Алгоритм запускается отдельно для каждой начальной вершины.

## Запуск

```bash
python3 app.py
```

После запуска откроется графический интерфейс. Матрица `D` вводится в левое
поле, а рассчитанная матрица `U` выводится в правом. Элементы строки разделяются
пробелами. Ноль вне главной диагонали означает отсутствие ребра. Вместо него
также можно написать `inf`, `∞` или `-`.

Кнопка «Рассчитать» запускает алгоритм, «Загрузить пример» возвращает исходный
пример, а «Очистить» очищает оба поля. Расчёт также запускается сочетанием
клавиш `Ctrl+Enter`.

Пример матрицы для шести вершин:

```text
0  7  9  0  0 14
7  0 10 15  0  0
9 10  0 11  0  2
0 15 11  0  6  0
0  0  0  6  0  9
14 0  2  0  9  0
```

Если путь между двумя вершинами отсутствует, в результирующей матрице
выводится знак `∞`. Отрицательные веса поддерживаются, но в графе не должно
быть циклов отрицательного веса.
