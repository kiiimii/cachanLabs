# Лабораторная работа №3 — топологическая декомпозиция

Программа принимает ориентированный граф в виде множества правых инциденций
`G+`, выделяет компоненты сильной связности (подсистемы), перечисляет вершины и
дуги каждой подсистемы и строит новый граф подсистем в виде матрицы
инцидентности `B`. Весь код находится в одном файле `app.py`.

## Запуск

```bash
python3 app.py
```

Дополнительные пакеты Python не нужны. Для интерфейса используется Tkinter.

## Формат ввода

Каждая строка задаёт вершину и вершины, в которые из неё выходят дуги:

```text
G+(1) = {2}
G+(2) = {3, 4}
G+(3) = {1}
G+(4) = {}
```

Также поддерживаются сокращённые формы `1: 2 3` и `1 -> 2, 3`. Пустое
множество задаётся как `{}`, `Ø`, `∅`, `-`, `0` или пустая правая часть.
Вершина, упомянутая только справа, автоматически добавляется с пустым `G+`.

Дуги исходного графа нумеруются по возрастанию номера начальной вершины, затем
по возрастанию номера конечной вершины. В матрице `B` используется соглашение:

- `+1` — дуга выходит из вершины;
- `−1` — дуга входит в вершину;
- `2` — дуга является петлёй.

Если несколько исходных дуг соединяют одну и ту же пару подсистем, в новом
графе они представлены одной дугой с указанием всех соответствующих исходных
номеров.
