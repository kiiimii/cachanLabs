                       1. Постановка задачи

     Детали изготавливаются в механическом цехе партиями и поступают в
операционный накопитель сборочного конвейера. Требуется определить точку
заказа и резервный запас, обеспечивающие вероятность остановки конвейера
из-за отсутствия деталей не более заданной. Затем необходимо оценить
вероятность переполнения накопителя и, если она превышает допустимое
значение, определить необходимое увеличение емкости.

1.2. Принятая вероятностная модель

      Потребление в разные часы считается независимым и одинаково
распределенным по нормальному закону. Тогда суммарное потребление X за
время изготовления и доставки партии также распределено нормально:

                                    X ~ N(mT; σ2T).

      Его математическое ожидание и среднее квадратическое отклонение
равны:

                            μT = mT = 23,4 · 5 = 117 шт.;

                           σT = σ√T = 3,9√5 = 8,7207 шт.

      Нормальное распределение является непрерывной аппроксимацией дискретного
числа деталей. Окончательные управляющие параметры округляются в безопасную
сторону до целого числа.


      2. Определение точки заказа и резервного запаса

      Заказ размещается при снижении текущего запаса до уровня R.
Остановка конвейера до поступления новой партии произойдет, если
потребление за срок поставки превысит этот уровень:

                               P{X > R} ≤ p1 = 0,02.
     Обозначим через Φ функцию распределения стандартной нормальной
случайной величины. Из условия надежности получаем:

                 R = μT + z0,98σT, где z0,98 = Φ−1(0,98) = 2,0537.

     Резервный (страховой) запас:

                    B = z0,98σT = 2,0537 · 8,7207 = 17,9101 шт.

     Теоретическая точка заказа:

                        R = 117 + 17,9101 = 134,9101 шт.

     Так как детали учитываются поштучно, принимаем R = 135 шт.
Фактический резерв относительно среднего расхода за срок поставки равен B =
135 − 117 = 18 шт. Проверка вероятности остановки:

            P{X > 135} = 1 − Φ((135 − 117)/8,7207) = 0,01951 ≈ 1,95 %.

     Полученная вероятность не превышает допустимые 2 %.

             3. Оценка вероятности переполнения

     К моменту поступления партии в накопителе остается R − X деталей.
Сразу после поступления партии запас Y составит:

                                   Y = R − X + Q.

     При принятой точке заказа R = 135 шт. случайная величина Y имеет
нормальное распределение с параметрами:

                        M[Y] = 135 − 117 + 255 = 273 шт.;

                               σY = σT = 8,7207 шт.

     Вероятность переполнения накопителя емкостью C = 200 шт. равна:
                    Pпер = P{Y > 200} = Φ((273 − 200)/8,7207)

                      = Φ(8,3709) ≈ 1 − 2,9 · 10−17 ≈ 100 %.

     Таким     образом,   существующий      накопитель     почти   наверняка
переполнится. Это согласуется и с непосредственной оценкой: емкость
накопителя 200 шт. меньше размера одной поступающей партии 255 шт.

              4. Определение необходимой емкости

     Требуемая емкость Cтр должна обеспечивать условие:

                             P{Y > Cтр} ≤ p2 = 0,035.

     Следовательно, емкость должна быть не меньше квантили уровня 1 −
0,035 = 0,965 распределения запаса после поставки:

                              Cтр ≥ M[Y] + z0,965σY,

                           z0,965 = Φ−1(0,965) = 1,8119;

                    Cтр ≥ 273 + 1,8119 · 8,7207 = 288,8011 шт.

     Принимаем минимальную целую емкость Cтр = 289 шт. Необходимое
увеличение:

                             ΔC = 289 − 200 = 89 шт.

     Проверка для выбранной емкости:

                      P{Y > 289} = 1 − Φ((289 − 273)/8,7207)

                   = 1 − Φ(1,8347) ≈ 0,03327 = 3,33 % < 3,5 %.
